# General Notes on Solving the Problem
## Problem Specification
- Given an integer array ```nums```, return ```true``` if any value appears more than once in the array, otherwise return ```false```.
## Solution 1
- First i implemented a brute force solution O(n<sup>2</sup>).
- It simply runs two loops i.e. for each element it checks for duplicate till end of the array.
## Solution 2
- In second Solution, i used a hashSet.
- As they are O(1), when it comes to searching.
- They represent the concept of generalized array.
